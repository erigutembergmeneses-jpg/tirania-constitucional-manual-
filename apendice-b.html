Apêndice B — Manual Operacional Preliminar do IPI e do SAPED

Instrumentos de codificação, cálculo, documentação e validação

B.1. Finalidade, alcance e estágio de desenvolvimento

Este apêndice reúne os instrumentos metodológicos propostos para a aplicação, a documentação, a auditoria e o aperfeiçoamento do Índice de Preservação Institucional (IPI) e do Sistema de Alerta Precoce para Erosão Democrática (SAPED), apresentados conceitualmente no Capítulo 9.

Sua finalidade não é reproduzir a fundamentação teórica do capítulo, mas oferecer recursos para compreender como a proposta pode ser operacionalizada, quais evidências deverão sustentar as avaliações e quais procedimentos ainda precisam de validação independente.

Importante: o IPI e o SAPED são apresentados aqui como propostas em desenvolvimento. A consulta Delphi ainda não foi realizada. Os indicadores, pesos e critérios não devem ser descritos como consensualmente validados ou empiricamente confirmados.

B.2.6. Regras transversais de codificação

  1. Identificar a variável original, a fonte, a versão, o período e a direção interpretativa antes de converter qualquer valor.
  2. Normalização linear: Xnorm = 10 × (X − Xmin) / (Xmax − Xmin), quando aplicável e justificada.
  3. Quando valores maiores representarem deterioração, inverter: Xinv = 10 − Xnorm.
  4. Não combinar escalas distintas sem registrar a transformação aplicada.
  5. Não realizar imputação automática de dados ausentes. Categorias: (a) ausência de informação; (b) indisponibilidade da fonte; (c) informação inconclusiva; (d) indicador inaplicável.
  6. O IPI agregado será "não calculável" quando qualquer dimensão não dispuser de pontuação válida.
  7. Codificação dupla: divergências superiores a 2 pontos serão encaminhadas a terceiro avaliador.

B.3. Protocolo proposto para consulta Delphi

Esta seção descreve um procedimento futuro de consulta a especialistas. A consulta não foi realizada até a preparação desta versão.

B.3.1. Objetivos

  • Avaliar a pertinência conceitual das cinco dimensões e dos 25 indicadores.
  • Identificar indicadores redundantes, ausentes, ambíguos ou de difícil mensuração.
  • Examinar os pesos relativos das dimensões.
  • Avaliar clareza, viabilidade de coleta, comparabilidade e regras de conversão.

B.3.2. Composição do painel — proposta inicial

Painel de 20 a 30 participantes: juristas constitucionais (30%), cientistas políticos (25%), especialistas em estatística ou mensuração (20%), jornalistas investigativos (15%) e representantes de organizações da sociedade civil (10%).

B.3.3. Rodadas propostas

  1. Rodada 1 — Consulta aberta: indicadores a excluir/reformular, dimensões ausentes, fontes inadequadas, justificativa dos pesos.
  2. Rodada 2 — Questionário estruturado: escala 1–7 para pertinência, clareza e viabilidade; distribuição de 100 pontos entre dimensões.
  3. Rodada 3 — Devolutiva e consolidação: estatísticas agregadas, síntese de justificativas e divergências persistentes.

B.3.4. Critérios de análise e consenso

Coeficiente de variação (CV) como medida de dispersão: consenso forte se CV ≤ 0,25; moderado entre 0,26 e 0,40; dissenso se CV > 0,40. Limiares provisórios. Devem ser complementados por mediana, intervalo interquartil e distribuição das respostas.

B.3.5. Produtos esperados

  1. Relatório metodológico com composição efetiva do painel e taxas de resposta.
  2. Matriz revisada com histórico das alterações.
  3. Recomendação sobre os pesos, sem ocultar dissensos.
  4. Dicionário de variáveis e regras de codificação atualizado.
  5. Registro de limitações e plano de validação subsequente.

B.4. Procedimentos de cálculo e reprodução

Fórmula:

IPI = 0,25·D1 + 0,20·D2 + 0,20·D3 + 0,20·D4 + 0,15·D5

Faixas interpretativas propostas:

  • 0 a menos de 4,0: preservação institucional muito comprometida.
  • 4,0 a menos de 6,0: fragilizada.
  • 6,0 a menos de 8,0: intermediária.
  • 8,0 a 10,0: relativamente elevada.

B.4.2. Implementação de referência em Python

PESOS = {"D1": 0.25, "D2": 0.20, "D3": 0.20, "D4": 0.20, "D5": 0.15}

def classificar_ipi(ipi):
    if ipi < 4:
        return "Preservação institucional muito comprometida"
    if ipi < 6:
        return "Preservação institucional fragilizada"
    if ipi < 8:
        return "Preservação institucional intermediária"
    return "Preservação institucional relativamente elevada"

def calcular_ipi(d1, d2, d3, d4, d5):
    dimensoes = {"D1": d1, "D2": d2, "D3": d3, "D4": d4, "D5": d5}
    ausentes = [k for k, v in dimensoes.items() if v is None]
    if ausentes:
        return {
            "ipi": None, "classificacao": None,
            "status": "NAO_CALCULAVEL",
            "dimensoes": dimensoes,
            "dimensoes_ausentes": ausentes
        }
    for nome, valor in dimensoes.items():
        if not isinstance(valor, (int, float)) or not 0 <= valor <= 10:
            raise ValueError(f"{nome} deve ser numérico e estar entre 0 e 10.")
    ipi = round(sum(dimensoes[k] * PESOS[k] for k in PESOS), 4)
    return {
        "ipi": ipi,
        "classificacao": classificar_ipi(ipi),
        "status": "CALCULADO",
        "dimensoes": dimensoes,
        "dimensoes_ausentes": []
    }

if __name__ == "__main__":
    resultado = calcular_ipi(8, 7, 6, 8, 5)
    print(resultado)  # IPI: 6.95; faixa intermediária

B.4.3. Implementação de referência em R

pesos <- c(D1 = 0.25, D2 = 0.20, D3 = 0.20, D4 = 0.20, D5 = 0.15)

classificar_ipi <- function(ipi) {
  if (ipi < 4) return("Preservação institucional muito comprometida")
  if (ipi < 6) return("Preservação institucional fragilizada")
  if (ipi < 8) return("Preservação institucional intermediária")
  return("Preservação institucional relativamente elevada")
}

calcular_ipi <- function(d1, d2, d3, d4, d5) {
  dimensoes <- c(D1 = d1, D2 = d2, D3 = d3, D4 = d4, D5 = d5)
  if (any(is.na(dimensoes))) {
    return(list(ipi = NA_real_, classificacao = NA_character_,
                status = "NAO_CALCULAVEL", dimensoes = dimensoes))
  }
  if (any(!is.finite(dimensoes)) || any(dimensoes < 0 | dimensoes > 10)) {
    stop("Todas as dimensões devem ser finitas e estar entre 0 e 10.")
  }
  ipi <- round(sum(dimensoes * pesos), 4)
  list(ipi = ipi, classificacao = classificar_ipi(ipi),
       status = "CALCULADO", dimensoes = dimensoes)
}

calcular_ipi(8, 7, 6, 8, 5)  # IPI = 6.95

B.6. Arquitetura projetada para dados e interoperabilidade

A descrição abaixo registra uma arquitetura de referência. Não significa que a API esteja implementada ou acessível. Endpoints, autenticação e formatos deverão ser confirmados quando houver implantação.

B.6.1. Princípios de projeto

  • HTTPS e respostas estruturadas em JSON (opcionalmente CSV).
  • Documentação versionada, idealmente compatível com OpenAPI.
  • Metadados claros: país, período, fontes, versão do método, data de atualização.
  • Identificadores persistentes e histórico de versões.
  • Interoperabilidade com V-Dem, WJP e IDEA, sem presumir equivalência.

B.8. Condições de uso, limitações e colaboração

A versão final deste apêndice deverá indicar a licença efetivamente adotada para textos, formulários e códigos. Se o material for publicado sob Creative Commons Atribuição 4.0 Internacional (CC BY 4.0), a reutilização deverá observar os termos dessa licença e manter a atribuição.

B.8.1. Limitações atuais

  • A matriz de indicadores e as regras de pontuação são preliminares.
  • A consulta Delphi ainda não foi realizada.
  • Os exemplos computacionais precisam ser testados em ambiente documentado.
  • A arquitetura da API é prospectiva e não comprova serviço público ativo.
  • Resultados do IPI não devem ser interpretados isoladamente como prova causal.
