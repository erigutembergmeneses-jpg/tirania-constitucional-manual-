##  Sobre

Vitrine interativa da obra **"A Tirania Constitucional: Como a Legalidade Pode Enfraquecer a Democracia"** de Erigutemberg Meneses.

Este repositório contém o manual executivo com conceitos, ferramentas e propostas para preservação institucional, além de materiais complementares para download.

##  Objetivos

- **Divulgar** contribuições teóricas e metodológicas da obra
- **Preservar** arquivos complementares em repositórios de acesso aberto
- **Permitir** download por pesquisadores, jornalistas e instituições

## 📥 Downloads

### Pacote 1 - Manual Metodológico IPI
- Texto integral do Capítulo 9 (PDF)
- Manual de codificação preliminar
- Scripts R/Python para cálculo do IPI
- Dicionário de variáveis
- Memória de cálculo

### Pacote 2 - SAPED e Observatório
- Descrição operacional do SAPED
- Formulários de registro padronizado
- Proposta de arquitetura da API pública

## 🔧 Ferramentas

### Índice de Preservação Institucional (IPI)
Fórmula: `IPI = 0,25D1 + 0,20D2 + 0,20D3 + 0,20D4 + 0,15D5`

### Sistema de Alerta Precoce (SAPED)
Quatro níveis de alerta: Verde, Amarelo, Laranja, Vermelho
